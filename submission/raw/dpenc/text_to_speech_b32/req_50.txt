In programming, **syntax** and **semantics** are two fundamental concepts that define how code is structured and what it means.

### 1. **Syntax**
- **Definition**: Syntax refers to the **rules and structure** of the programming language. It defines how code must be written to be valid.
- **Focus**: It's about the **form** of the code — the arrangement of symbols, keywords, punctuation, and structure.
- **Example**: In Python, `print("Hello, World!")` is syntactically correct. But `print "Hello, World!"` (without parentheses) would be a **syntax error** in Python 3.
- **Error Type**: If your code violates syntax rules, the compiler or interpreter will **not run** it and will throw a **syntax error**.

### 2. **Semantics**
- **Definition**: Semantics refers to the **meaning** of the code. It defines what the code actually does when executed.
- **Focus**: It's about the **behavior** and **logic** of the program.
