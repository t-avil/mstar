The key principles of object-oriented programming (OOP) are fundamental concepts that guide the design and implementation of software using objects. These principles promote code reusability, maintainability, and scalability. The four main principles of OOP are:

1. **Encapsulation**  
   - **Definition**: Bundling data (attributes) and methods (functions) that operate on the data into a single unit called an object. It also involves restricting direct access to some of an object's components, which is typically achieved using access modifiers like private, protected, and public.
   - **Purpose**: To hide internal implementation details and protect the integrity of the data. This allows for better control over how data is accessed and modified.
   - **Example**: A `BankAccount` class might have a private balance variable and public methods like `deposit()` and `withdraw()` to modify it safely.

2. **Abstraction**  
   - **Definition**: Hiding complex implementation details and exposing only the essential features of an object. It allows users to interact with objects through a simplified interface without needing to understand the underlying complexity.
