In programming, **syntax** and **semantics** are two fundamental concepts that define how code is structured and what it means. Here's a breakdown of the difference:

### 1. **Syntax**
- **Definition**: Syntax refers to the **rules** that govern how code must be written in a programming language.
- **Focus**: It's about the **structure** and **format** of the code.
- **Example**: In Python, the syntax for a `for` loop is:
  ```python
  for i in range(5):
      print(i)
  ```
  If you write `for i in range(5) print(i)` (missing the colon), it's a **syntax error** because it violates the language's rules.

- **Key Point**: Syntax errors are caught by the compiler or interpreter during parsing. The program won't run until syntax is fixed.
