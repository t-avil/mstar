### What is Recursion?

**Recursion** is a programming technique where a function calls itself to solve a problem. It's like a loop, but instead of repeating steps using `for` or `while`, the function repeats by calling itself.

Think of it like this:

> "To solve a big problem, break it into smaller versions of the same problem until you reach a simple case that you can solve directly."

---

### The Two Key Parts of Recursion

Every recursive function has two main parts:

1. **Base Case**  
   This is the condition that stops the recursion. Without it, the function would keep calling itself forever (like an infinite loop), which causes a **stack overflow** error.

2. **Recursive Case**  
   This is where the function calls itself with a smaller or simpler version of the problem.
