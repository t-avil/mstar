# scratch/ — archived from /home/tim

Working scripts and analysis notes that lived loose in the home directory,
committed here so the home dir could be cleaned without losing them. Nothing
here is part of the build; it is bench//analysis tooling and session notes.

`scripts/` — launch wrappers, sweep drivers, A/B and parity helpers. Paths are
mostly absolute and machine-specific (GPUs 6/7, /m-coriander/coriander/tim/...),
so treat them as references rather than portable tools.

`notes/` — review write-ups and research notes (native encoders, encoder-v4,
CUDA-graph/compile/batching research, flag decompositions, experiment log).
Point-in-time analysis; some conclusions were later retracted or superseded —
see the git history on the benchmark dirs for what actually held up.

CLAUDE.md was deliberately left in the home directory, not archived here.
