**B32 step (~30.7ms ITL): thinker GPU 49% idle.** Decode graph 12.8ms GPU (76% = fused_moe_kernel ~100.9µs avg ≈ bf16 bandwidth floor; attention 0.72ms; router topk 0.68ms). Python per step ≈26ms across two GIL-sharing threads: postprocess_batch 13.2ms (check_stop 2.0, route_outputs 2.5, register_outputs 3.5=SHM file per 4-byte token) + send_outputs 4.75ms (was doing 32 default-stream `.cpu()` syncs) + prepare_inputs 3.5ms (32 per-rid embed_tokens launches). Prefill+encoder graphs amortize +8.7ms/decode-step (phased batching; encoder 17.6ms + thinker prefill 27.5ms per admission serialized on the thinker GPU). **The CPU floor and prefill serialization, not the forward, are the B32 gap to vLLM.** B1: graph 5.1ms (MoE 1.52ms = 30%) + ~3.7ms bubbles; vLLM whole step 4.7ms.
